## Audit provenance

The release identifiers, filenames, file sizes, supported game versions, and published SHA-1 values were audited against the official [Modrinth project API](https://api.modrinth.com/v2/project/zAIE84Ch/version) and [CurseForge file-list API](https://www.curseforge.com/api/v1/mods/1323980/files?pageIndex=0&pageSize=100&sort=dateCreated&sortDescending=true). SHA-256 values were computed from the official CurseForge downloads. For every row, the computed SHA-1 matched Modrinth's published SHA-1, and the two marketplaces exposed the same filename, size, and artifact bytes.

The embedded Fabric game-version range is `~<Minecraft version>` for every Fabric artifact. The embedded NeoForge range is `[<Minecraft version>,1.22)` for every NeoForge artifact. Both marketplaces list the exact Minecraft version shown in each row.

> Frozen support applies only to the exact Minecraft version shown. Historical embedded loader ranges are resolver metadata, not a support, compatibility, testing, or update claim.

## Source provenance and retention

The [`pre-stonecutter-oracle`](https://github.com/AkaNebur/Quick-Skin-Mod/tree/pre-stonecutter-oracle) tag points to commit `ae872376b665c6040f395086f1fab416587555e0` and preserves the old per-version source roots. It postdates these artifacts and is a migration oracle, not exact binary provenance: release 2.6.2.4 was uploaded on March 6, 2026, before `mod_version=2.6.2.4` was committed on March 9, 2026, while release 2.6.2.5 was uploaded on March 10, 2026, before `mod_version=2.6.2.5` was committed on March 14, 2026.

The retained `src/v*` roots exist for parity checks and migration-oracle use through the first two successfully published, release-gate-green releases of the current architecture. They do not imply fixes or support for frozen versions. Removing them also requires migrating any remaining active resource references first.
