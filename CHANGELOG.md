# Update - 2.6.1.1
## Added

* **Added compatibility with the "Ears" mod**
> If you use the Ears mod, you can directly use the skins you create in Quick Skin.

* **Allow players without the mod to join servers that have it installed**
> Players without the mod will see other players without the skins they are using from the mod, but at least it will allow them to join the server.

* **Essential mod compatibility**
> Now, if you have the Essential mod, my mod will disable the model shown, so you don't have two duplicate models in the menus. It will also change the button to enter and readjust it so that it is next to the Essential's button.
> The player model that comes with Essential will directly take the skin you have selected.

## Fixes
* **Fixed bug with animated capes when using the "Wavey Capes" mod**
> The capes were completely broken, showing all the frames of the cape animation when using that mod. Everything should now work correctly.

* **No more crashes when using the arrow keys in the list of skins**

* **Adjustments to translations into different languages**
